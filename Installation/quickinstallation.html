🚀 Trength – Quick Installation Guide

Complete installation in 5–10 minutes

📝 Step 1: Register & Get Installation Code

  • Register yourself for Trength.
  • A unique installation code is sent to your email ID.
  • Keep this code ready for setup.
Screenshot: Registration page + Email with installation code

⬇️ Step 2: Download & Install

  • Download the Trength setup file.
  • Double-click the setup to start installation.
  • Enter the installation code when prompted.
  • Complete the setup wizard.
Screenshot: Setup wizard with installation code field highlighted

🔄 Step 3: Restart System

  • Restart your computer after installation.
  • This ensures Trength services start correctly.
Screenshot: Restart prompt / system restarting

🔔 Step 4: Verify Trength is Running

  • Check the system tray near the clock.
  • Confirm the Trength logo is visible.
Screenshot: System tray showing Trength icon

🌐 Step 5: Configure Network (One-Time Setup)

  • Wi-Fi: Select and configure your Wi-Fi network.
  • Ethernet: Ensure cable is connected and configure.
This setup is required only once and needs to be repeated only if router or network settings change.
Screenshot: Network setup screen (Wi-Fi & Ethernet options)

✅ Step 6: Check Connectivity

  • From the tray menu, click Check Connectivity.
  • Look for a success message.
Screenshot: Connectivity success message

⬆️ Step 7: Update Trength (Optional)

  • From the tray menu, check for updates.
  • Internet connection is required.
Screenshot: Tray menu showing update option

▶️ Step 8: Launch Trength

  • Click the Trength logo from the system tray.
  • The application will start.
Screenshot: Trength launching

🔐 Step 9: Login

  • Login screen is displayed.
  • Enter credentials to begin using Trength.
Screenshot: Trength login page

🛠 Quick Troubleshooting

❓ Trength logo not visible: Restart system, check installation status.
❓ Installation code rejected: Re-enter code, check expiry and email ID.
❓ Connectivity check fails: Verify Wi-Fi/Ethernet and router settings.
❓ Unable to update: Check internet and firewall/proxy.
❓ Application does not launch: Restart system and verify tray icon.
