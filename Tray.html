BACKGROUND RUNTIME AGENT SYSTEM UTILITY

Trength™ System Tray Application

The Trength Tray Application is a lightweight Windows background notification service that runs silently in your system taskbar. It monitors backend service health, database connectivity, and local port listeners, providing showroom staff and administrators with one-click operational controls.

Quick Taskbar Access: Look for the golden Trength emblem in the bottom-right Windows taskbar notification tray (next to the clock). Right-click the icon at any time to open configuration dashboards, restart local services, or check runtime diagnostics.
1

Tray Context Menu & Quick Actions

Right-clicking the Trength Tray icon reveals direct administrative controls for immediate store operations without navigating through Windows Service Manager:

Command Centre

Launches the network adapter bindings, IP configurations, and firewall management console.

Troubleshooter

Instant diagnostics for database connectivity, local firewall exceptions, and counter socket reachability.

Service Controller

Start, stop, or restart the background Trength Windows Service daemon with a single click.

Launch Web POS

Opens the default web browser directly to the showroom billing portal on the configured port.

Audit & Event Logs

Quick shortcut to open the active error logs and transaction sync journals for auditing.

Safe Exit

Cleanly detaches counter sessions, flushes database queues, and shuts down the local agent.

2

Real-Time Tray Status Badges

Hovering over or inspecting the tray icon provides instant visual feedback on store server readiness:

Icon Indicator Daemon State Operational Meaning Recommended Action
Active (Green) Running Web API listening, database connected, showroom counters communicating normally. None. System is operating normally.
Initializing (Amber) Starting Windows service is launching or local SQLite/SQL database connection is synchronizing. Allow 5-10 seconds for service spin-up to complete.
Stopped (Red) Halted Background service is paused or an IP port conflict is preventing socket binding. Right-click Tray → Select Restart Service or open Troubleshooter.

Always-On Local Network Service

The Trength Tray application registers itself with Windows Startup. When the store server or cashier PC boots, the service daemon immediately initiates port listeners, ensuring that tablet tills, mobile counters, and barcode scanners can connect instantly without manual intervention.
