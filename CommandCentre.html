Configurations

The Command Centre Configurations provides centralized administrative control for managing system-level configurations including Network Settings, Windows Services, and Application Controls.

1. Network Configurations

Network Configuration Screen
(Insert actual screenshot here)

Configure connectivity settings required for the system to operate within your local environment.

  • Wi-Fi Setup – Select and configure wireless network.
  • Ethernet (LAN) – Ensure LAN cable is properly connected.
  • Router Configuration – Set IP and port mapping if required.
Note: This is typically a one-time setup unless your router or network settings change.

2. Windows Service Management

Windows Service Control Screen
(Insert actual screenshot here)

Manage background services directly from the Command Centre interface.

  • Start Service
  • Stop Service
  • Restart Service
  • View Current Status
Important: Services must remain running for uninterrupted system functionality.

3. Application Controls

Application Control Panel
(Insert actual screenshot here)

Perform high-level operational controls without entering the core system.

  • Launch Application
  • Check Connectivity
  • Update Software (Internet Required)
  • View Current Version
Note: Software updates require an active internet connection.

Operational Notes

Service Not Starting?
Ensure Windows permissions allow service execution.
Connectivity Fails?
Re-check network configuration and router settings.
