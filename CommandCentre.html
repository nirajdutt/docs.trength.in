Command Centre: Network & Service Configurations

The Trength Command Center provides a centralized control dashboard to manage network adapter bindings, oversee the background Windows service daemon, monitor the Web API runtime engine, and enable local DNS discovery for showroom terminals and mobile sales tablets.

Administrator Elevation Required: To bind network adapters, open inbound firewall ports, and toggle system services, launch Command Center with administrator rights. Right-click the golden Trength Tray Icon and select Command Centre, or run CommandCentre.exe as Administrator.

Configuration Rules & Operational Best Practices

Wi-Fi & AP Isolation Requirement

Many retail routers enable Access Point (AP) Isolation by default to prevent wireless devices from discovering each other. AP Isolation MUST be disabled in your showroom router settings so tablet devices can reach the counter workstation's IP address.

mDNS Local Discovery Protocol

With DNS Discovery enabled, secondary terminals and iPads auto-detect trength-server.local over the LAN without requiring manual IP typing. Keep this toggle enabled at all times.
