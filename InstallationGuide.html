Install Trength™ Suite

Get your shop ready for billing in a few simple steps.

You don't need to be a computer expert!

Simply follow the easy screens shown below. Trength automatically handles all technical configurations in the background so you can focus on running your store.

1

Before You Install Trength

Make sure you have these 3 simple things ready before starting:

🖥️

Windows PC

Windows 10 or Windows 11 (64-bit edition).

🌐

Internet Connection

Required for initial activation and software updates.

👤

Administrator Access

Windows may ask for permission during installation.

IMPORTANT CONCEPT

Does Trength Require Internet?

No — Trength runs 100% offline. You can bill customers, print receipts, and manage stock with zero internet required.
🌐 Internet Connection
Used for license activation, software updates, and cloud backup.
📶 Local Showroom Wi-Fi / LAN
Allows billing counters, back-office PCs, and mobile tablets to talk to each other.
💻 Single Standalone PC
A single PC can operate 100% locally with zero internet or local network needed.
2

Follow These Simple Screens

STEP 1 OF 5

Launch Trength Setup

Double-click TrengthSetup.exe on your computer. When the Setup Wizard opens, simply click Next >.

Trength Setup — Step 1
STEP 2 OF 5

Choose Where Trength Will Be Installed

Trength automatically suggests the best location on your computer:

C:\Program Files (x86)\Trength Suite\

👉 For most users, simply leave the default location and click Next.

Trength Setup — Step 2
STEP 3 OF 5

Choose Your Connection Type

Select WIFI if your computer uses wireless internet, or ETHERNET if connected via network cable. Then click Next >.

Trength Setup — Step 3
STEP 4 OF 5

Confirm & Start Installation

Click Next > to start copying files. If Windows displays a permission prompt (UAC), click Yes.

Trength Setup — Step 4
STEP 5 OF 5

Windows Administrator Permission (UAC)

When Windows displays a User Account Control (UAC) prompt asking "Do you want to allow this app to make changes to your device?", click Yes to grant administrator permission.

Windows Security — UAC Prompt
Step 1 of 5
🔄

Restart Your Computer

Please restart your computer before opening Trength for the first time.

This allows Trength's background services to start correctly.

👍 Don't worry — your installation is complete!
3

Checking Trength Status (System Tray Icon)

After restarting, look at the bottom-right corner of your screen near the clock. Click the small upward caret (^) to find the golden Trength "त्र" icon.

🟢

Green Icon

Running Normally: All POS database and network services are active.

🟠

Orange Icon

Attention Required: POS is working locally, but local network or internet update is reconnecting.

🔴

Red Icon

Service Stopped: Background POS service needs to be restarted.

4

Troubleshooting & Support

Trength isn't opening? Try these 3 things first:

1
Restart Your PC

Solves 90% of temporary connection glitches.

2
Check Tray Icon

Ensure the golden "त्र" icon near clock is Green.

3
Check Connectivity

Right-click tray icon → select "Check Connectivity".

Still not working? Advanced Technical Troubleshooting

If Trength POS service remains stopped, your IT technician can perform these steps:

  1. Press Win + R, type services.msc, and press Enter.
  2. Locate Trength POS Service in the list.
  3. Right-click it and select Restart.
  4. Verify that Windows Firewall allows inbound connections on port 8080 and 443.
