Quick Installation & Setup Guide

Follow this step-by-step technical walkthrough to install, register background services, and initialize Trength Jewellery Software on your retail billing workstations and back-office servers.

System Prerequisites & Hardware Requirements

  • Operating System: Windows 10 / 11 (64-bit) or Windows Server
  • Processor: Intel Core i3 / AMD Ryzen 3 or higher
  • RAM: 4 GB minimum (8 GB recommended for multi-counter POS)
  • Storage: 500 MB free SSD/HDD storage for database cache
  • Privileges: Windows Local Administrator account
  • Network: Wi-Fi or Ethernet LAN with static local subnet
1

Phase 1: Registration & Software Download

Step 1: Obtain Your Unique Installation Code

Prior to downloading the software, register your store license on the Trength partner portal. Upon successful verification of your company details (GSTIN, store location, and administrator identity), a 16-character alphanumeric Installation Code is generated and sent to your registered email address.

Security & Licensing: The installation code securely binds your local retail database with your cloud backups, customized billing templates, and user permission matrices. Keep this code confidential and readily available.

Step 2: Run the Trength Setup Installer

Download the setup bundle provided in your onboarding email (e.g. Trength-Setup-v1.0.exe).

  1. Locate the downloaded setup file in your Downloads folder.
  2. Right-click the executable and select Run as Administrator.
  3. If prompted by Windows Defender SmartScreen ("Windows protected your PC"), click More info and then choose Run anyway.
  4. When the license activation prompt appears, paste your unique Installation Code and click Verify.
  5. Select the destination directory (Default: C:\Program Files\Trength\) and complete the installation wizard.
The installer automatically deploys the core desktop application, local SQLite/SQL database engine, barcode label drivers, and the Trength Background Windows Service.
2

Phase 2: System Restart & Service Verification

Step 3 & 4: Restart Workstation & Verify System Tray Icon

Once setup finishes, reboot your computer. Restarting allows Windows to register the system service hooks and load background network daemon processes before the POS application starts.

Locating the Trength Tray Monitor:
  1. Navigate to the bottom-right corner of your screen (near the date and clock).
  2. Click the small upward caret ^ to view the Notification Area overflow tray.
  3. Verify that the golden Trength "त्र" Icon is visible and active.
System Tray Menu Options:
Menu Item Function
Launch Trength Opens the primary jewellery POS application and billing console.
Check Connectivity Validates local network status, cloud sync connection, and database health.
Update Software Fetches updated GST rates, bullion metal prices, and software patches.
Command Centre Administrative utility to restart services, inspect network ports, and pair mobile devices.
3

Phase 3: Store Network Configuration & Testing

Step 5 & 6: Configure Store Network & Run Connectivity Test

Trength is architected for continuous retail reliability. It operates both offline (instant counter billing) and synchronized across devices (sales reps using tablets on the showroom floor). To allow mobile devices to discover the workstation, network connectivity must be configured once:

Wi-Fi Network Setup

Connect the workstation to your secure showroom Wi-Fi network. Ensure that client isolation (AP isolation) is disabled on your router so paired mobile devices can reach the POS terminal.

Wired LAN (Ethernet)

For main checkout and cashier counters, a wired Ethernet cable is strongly advised to eliminate wireless packet drops during weighing scale input and invoice printing.

Running the Connectivity Diagnostics:
  1. Right-click the golden Trength tray icon.
  2. Select Check Connectivity from the context menu.
  3. A green toast notification reading "Success: Network & Database Services Active" will appear on screen.
Important: This network setup is a one-time process. It only needs to be re-run if you change your store router, IP subnet, or Wi-Fi password.

Step 7: Check for Software Updates & Rate Tables

From the tray menu, click Update Software. Trength checks the secure cloud repository for the latest jewellery tax updates, standard gold/silver purity tables, and system enhancements. Internet connectivity is required during this step.

4

Phase 4: Launching Trength & First-Time Login

Step 8 & 9: Launch Application & Enter Store Credentials

Click the Trength tray icon or the desktop shortcut created during setup to launch the POS window.

First-Time Login Checklist:
  • Store / Branch ID: Pre-filled from your installation code verification.
  • Operator Username & Password: Enter the administrator credentials provided in your onboarding email.
  • Billing Counter: Select your designated counter (e.g., Counter 01 - Gold Ornaments).
  • Click Sign In to enter the main dashboard. Daily gold bullion rates will automatically load.

Troubleshooting & FAQs

Tray Icon is not visible after computer restart

Check if the Windows service was prevented from starting on boot:

  1. Press Windows Key + R, type services.msc, and hit Enter.
  2. Scroll down and find Trength Service.
  3. Check the Status column. If it is blank or stopped, right-click it and choose Start.
  4. Ensure the Startup Type is set to Automatic.

"Installation Code Rejected or Invalid" during setup

Installation codes are strictly 16 characters and case-sensitive. Verify there are no leading or trailing whitespace characters when pasting the code. Ensure the machine has active internet access during activation so the installer can query the central license registry.

Network Connectivity Check fails

If the connectivity test returns an error:

  • Check that your LAN cable is securely plugged in, or that your Wi-Fi is connected to the showroom router.
  • Ensure your router or third-party antivirus firewall is not blocking internal TCP traffic on Port 8082 (used for terminal pairing).
  • Open Windows Defender Firewall with Advanced Security and confirm that inbound connections for Trength are permitted on Private Networks.
