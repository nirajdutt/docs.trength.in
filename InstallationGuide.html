Quick Installation Guide

Follow the steps below to install and configure Trength Jewellery Software. The entire process takes approximately 5–10 minutes.

1. Register & Receive Installation Code

Screenshot Placeholder
(Insert actual application screenshot here)

Register yourself on the Trength platform. A unique installation code will be sent to your registered email ID.

Important: Keep this installation code ready. It will be required during setup.

2. Download & Install

  • Download the Trength setup file.
  • Double-click the setup file.
  • Enter the installation code when prompted.
  • Complete the installation wizard.

3. Restart Your System

After installation completes, restart your computer to ensure all Trength services start correctly.

4. Verify System Tray Icon

After restart, check the system tray (near the clock). Confirm that the Trength logo is visible.

5. Configure Network Settings (One-Time Setup)

Set up network connectivity for offline usage:

  • Wi-Fi: Select and configure your Wi-Fi network.
  • Ethernet: Ensure LAN cable is connected and configured.
Note: This setup is required only once and must be repeated only if your router settings change.

6. Check Connectivity

From the tray menu, click Check Connectivity. Ensure you receive a Success Message.

7. Update Software (If Available)

From the tray menu, you can update Trength to the latest version. Internet connection is required for updates.

8. Launch Trength

Click on the Trength tray icon to start the application.

9. Login

The login page will be displayed. Enter your credentials to begin using Trength.

Quick Troubleshooting

Tray Icon Not Visible?
Restart your computer and check again.
Installation Code Not Accepted?
Verify the code from your registered email and re-enter carefully.
Connectivity Failed?
Re-check Wi-Fi/Ethernet settings and router configuration.
